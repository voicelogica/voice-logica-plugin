# Create a Voice Logica support ticket

Open the ticket in the Voice Logica app through MCP support tools. Do not send the user to email unless the MCP has no ticket tool.

## When to file

- The user asks to open a ticket, escalate, or get a human.
- A call or agent issue is still broken after one honest diagnosis pass.
- Billing, number porting, carrier, or account-access issues.

Do not file a ticket for a simple setting change you can do in the same chat.

## What to put on the ticket

Collect before creating:

1. Short subject (what failed, not "help")
2. Expected vs actual
3. Agent name and ID
4. Call ID(s) if it is a call issue
5. When it started / whether it used to work
6. What you already tried

Write the body in the user language. Include IDs as plain text. Do not invent Call IDs.

## How to create it

1. Look at the Voice Logica MCP tools for support or tickets (create / list / reply).
2. Create the ticket with the subject and body above.
3. Return the ticket ID and a one-line summary of what you filed.
4. If create fails, say so and give the Support portal link: https://support.voicelogica.ai

## After create

Do not keep editing the agent unless the user asks. Offer to add a Call ID or recording if they have one.
