# Manage Voice Logica phones

Use Voice Logica MCP phone tools. Do not invent numbers, SIP credentials, or agent IDs.

## What this covers

- List VoIP phones and registrations
- See which number is on which agent
- Register or update a phone
- Assign a DID / inbound number to an agent
- Explain a missing phone badge on an agent

## Before changing anything

1. List phones and list agents. Match by name, then use real IDs.
2. If the user names a number, find that exact registration first.
3. Confirm the target agent before assigning or moving a number.

## Common jobs

**Why does this agent have no phone?**
An agent with no DID usually needs a number from Phones, or a plan that includes DIDs. Check phones first, then the agent, then billing if the plan has no number feature.

**Assign a number to an agent.**
List free or existing phones, pick one, attach it to the agent ID, then confirm the agent shows that number.

**New phone / SIP registration.**
Ask for the destination agent and any number they already own. Create or register through MCP. Never make up SIP passwords or print secrets in chat.

**Transfers vs phones.**
Phones are the numbers and registrations. Transfer destinations live on the agent Transfer Connection tab. Do not mix them up.

## After a change

Say which number is now on which agent. Suggest a test inbound call.
